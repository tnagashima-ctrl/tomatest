# 土地・物件探索フォーム：バックエンド連携仕様

LP（STUDIO）に設置したフォームから、Cloudflare Pages（`https://where-sim.pages.dev`）の API に送られるデータの仕様です。バックエンド担当の方向けにまとめています。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `land-search-form.html` | フォーム本体（画面表示と入力チェック） |
| `where-lead-bridge.html` | 連携コード。フォームの入力値を読み取り、`/api/lead` に送信する |

バックエンドが受け取るのは、`where-lead-bridge.html` が送る `/api/lead` へのリクエストです。

## 今回の変更点（バックエンド側で対応が必要）

`/api/lead` に次の3項目が追加で届くようになりました。Slack 通知や保存の対象に加えてください。

| キー | 内容 | 例 |
|---|---|---|
| `position` | 役職 | `部長・マネージャー` |
| `purchase_method` | 現在の土地・物件の仕入れ方法 | `直接仕入れと仲介情報の両方を活用` |
| `purchase_policy` | 今後の土地・物件の仕入れ方針 | `今後、直接仕入れを行っていきたい` |

未対応のままでもエラーにはなりませんが、値は使われずに捨てられます。

## API 1：`POST /api/lead`

フォーム送信時に呼ばれます。

### リクエスト

- ヘッダー：`Content-Type: application/json`
- `mode: "cors"` で送信します。LP は別ドメインなので、プリフライト（`OPTIONS`）への応答と CORS ヘッダーが必要です。

### ボディ例

```json
{
  "name": "山田 太郎",
  "email": "taro@example.com",
  "company": "株式会社〇〇",
  "position": "部長・マネージャー",
  "tel": "090-1234-5678",
  "pref": "東京都",
  "purchase_method": "直接仕入れと仲介情報の両方を活用",
  "purchase_policy": "今後、直接仕入れを行っていきたい",
  "token": "abc123",
  "source": "1to1フォーム営業",
  "page": "https://example.studio.site/lp"
}
```

### 項目一覧

| キー | 内容 | このフォームでの有無 | 備考 |
|---|---|---|---|
| `name` | 氏名（姓と名を半角スペースで連結） | 必ずあり | |
| `email` | メールアドレス | 必ずあり | |
| `company` | 会社名 | 必ずあり | |
| `position` | 役職 | 必ずあり | **新規**。値は下記の選択肢から |
| `tel` | 電話番号 | 必ずあり | 数字・ハイフン・括弧・+ など 9〜15 文字 |
| `pref` | 都道府県 | 必ずあり | キー名は `prefecture` ではなく `pref` |
| `purchase_method` | 現在の仕入れ方法 | 必ずあり | **新規**。値は下記の選択肢から |
| `purchase_policy` | 今後の仕入れ方針 | 必ずあり | **新規**。値は下記の選択肢から |
| `city` / `use` / `area` / `station` | 市区町村・想定用途・想定面積・駅距離 | なし | 連携コードは他の LP と共通のため定義だけある。該当する入力欄があるフォームでのみ届く |
| `token` | LP の URL の `?t=` の値 | 常にあり | URL に無ければ空文字 `""` |
| `source` | 流入元 | 常にあり | 現在は固定で `1to1フォーム営業` |
| `page` | 送信元ページの URL（`#` 以降は除く） | 常にあり | |

- 値が空の項目は、キーごと送られません。
- 連携コードは `email` と `pref` の両方が取れたときだけ送信します。
- フォーム側で必須項目がすべて入力済みでないと送信されません。
- 同じ内容の送信は 5 秒以内なら 1 回にまとめられます。

### 選択肢の値（届く文字列そのまま）

`position`
- 取締役・社長
- 部長・マネージャー
- 課長・リーダー
- 主任・担当者
- フリーランス

`purchase_method`
- 自社で土地・物件を直接仕入れている
- 直接仕入れと仲介情報の両方を活用
- 仲介業者の情報のみを活用
- 現在土地や物件の仕入れは行っていない

`purchase_policy`
- 今後、直接仕入れを行っていきたい
- 今後、直接仕入れを行う予定はない

選択肢の文言を変えるときは、事前にフォーム担当（長島）へ連絡してください。届く文字列も変わります。

### レスポンス

- 必ず JSON で返してください。JSON 以外だと LP 側では通信エラー扱いになります。
- 成功時は HTTP 2xx で、遷移先 URL を `url` に入れて返してください。LP は 0.6 秒後にこの URL へ移動します。

```json
{ "url": "https://where-sim.pages.dev/result?id=xxxx" }
```

- `url` が無い場合や 2xx 以外の場合、LP はブラウザのコンソールに警告を出すだけで、画面は送信完了表示のまま移動しません。

## API 2：`GET /api/company?t=<token>`

LP 表示時に呼ばれます。返した会社名で、LP 内の `{{会社名}}` を置き換えます。

```json
{ "company": "株式会社〇〇" }
```

失敗した場合や `company` が無い場合は「貴社」と表示されます。

## 送られていない項目

「探索したい土地・物件種別」（空き地・月極駐車場などの複数選択）は、現在 `/api/lead` に送られていません。必要な場合はフォーム担当に連絡してください。

## 動作確認のしかた

LP の URL に `?where_debug=1` を付けて開くと、ブラウザのコンソールで次を確認できます。

- 表示から 2 秒後：各項目をどの入力欄から読み取ったかの一覧
- 送信時：実際に送る値の一覧と、`/api/lead` の応答
