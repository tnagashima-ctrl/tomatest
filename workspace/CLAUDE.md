# ワークスペース運用ルール

ユーザー: 長島（株式会社WHERE / マーケティング全般）

## 目的
Notion・Gmail・Slack を走査し、タスク表 `TASKS.md` と日次ログ `daily/YYYY-MM-DD.md` を更新する。

## ファイル
- `TASKS.md`: 現在のタスク表（唯一の正）。
- `daily/YYYY-MM-DD.md`: その日の走査結果・新着・要返信の一覧。
- `archive/`: 完了タスクの退避先（月単位 `YYYY-MM.md`）。

## TASKS.md の形式
```
| ID | タスク | 状態 | 期限 | 出典 | リンク | 更新日 |
```
- 状態: 未着手 / 進行中 / 待ち / 完了
- 出典: Notion / Gmail / Slack / 手動
- ID は `T-0001` 形式の連番。既存IDは変更しない。
- 同じ依頼は重複追加せず、リンクまたは件名で既存行と照合して更新する。
- 手動で追記された行（出典=手動）は削除・書き換えしない。

## 走査ルール
- 走査範囲: 前回実行以降（初回は過去3日）。
- Notion: 自分にアサインされたページ・DB行、期限付きタスク、更新のあったページ。
- Gmail: 受信の未返信スレッド、依頼・期限を含むもの。ニュースレター・広告は無視。
- Slack: 自分宛メンション、DM、自分がスレッドで返信待ちのもの。
- 読み取り専用。メール送信、Slack投稿、Notion編集は行わない。
- 返信が必要なものは `daily/` に返信案を書く（送信はしない）。

## 文体
- 簡潔に書く。装飾的な前置きや挨拶は書かない。
- メール返信案: 冒頭に宛名（例: 田中様）、本文は事務的で簡潔に。
